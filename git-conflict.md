Где возник конфликт

Конфликт возник в файле README.md.

Одна и та же строка была изменена одновременно в двух ветках:

main;
feature/readme.

Git не смог автоматически определить, какой вариант необходимо оставить.

Причина

В ветке feature/readme строка была изменена на:

Библиотека книг — учебный проект для создания каталога книг.

В ветке main строка была изменена на:

Библиотека книг — учебный проект для хранения каталога книг.

После выполнения merge возник конфликт.
