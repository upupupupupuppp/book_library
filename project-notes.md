Project Notes — Библиотека книг
Назначение

Проект представляет собой будущую систему для работы с каталогом книг.
Основная задача системы — хранить информацию о книгах и предоставлять возможность работать с каталогом.

## Поиск книг

Пользователь сможет искать книги по названию, автору и жанру.






## Дополнительная функция

В будущем пользователь сможет отмечать книги как прочитанные.
